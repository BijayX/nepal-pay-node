# Security policy

This library sits on a payment path, so security reports are handled first.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private reporting instead:
**Security → Report a vulnerability** on this repository.

Include the affected version, a description, and steps or code to reproduce.
You will get an acknowledgement within 72 hours and a fix or mitigation plan
within 14 days for confirmed issues.

## Supported versions

Only the latest minor release receives security fixes.
